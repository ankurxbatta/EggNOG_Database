# Genomic data integration — functional annotation

Bioinformatics coursework: taking an assembled genome and working out what its
genes *do*, by integrating structural annotation with functional annotation from
the **eggNOG** orthology database.

## What it does

- Structural annotation — locating genes and features on the genome
- Functional annotation — assigning biological meaning via eggNOG orthologous
  groups
- Integrating the two into a single annotated picture of the genome

## Tools

R / Quarto (`Genomic_Data_Integration.qmd`); environment defined in `Env.R`.

## Running it

Open `Genomic_Data_Integration.qmd` in RStudio and render.

Part of the Genomics & Transcriptomics microcredential (Langara College).
